## 0.1.0-dev.1

- 初始开发版本。
- 新增 QQ / QQ 空间分享 Provider 的 Dart API 和 MethodChannel 实现。
- Android 接入 QQ 官方 Lite Jar，支持 QQ 好友网页 / 图片分享和 QQ 空间网页分享。
- iOS 接入 QQ 官方 Lite XCFramework，支持 QQ 好友网页 / 图片分享和 QQ 空间网页分享。
- 新增 Android Activity result 回调和 iOS URL / Universal Link 回调处理。
- 新增隐私授权、Provider 分发、能力判断和结果映射测试。
