Shared Flutter platform interface for Share Bridge federated plugins.

This package is intended for platform implementation packages such as `share_bridge_wechat_android`, `share_bridge_wechat_ios`, `share_bridge_qq_android`, and their HarmonyOS counterparts. Application code should normally depend on `share_bridge_wechat`, `share_bridge_qq`, or `share_bridge_core` instead.
