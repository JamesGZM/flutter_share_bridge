# Release Checklist

- Verify package names on pub.dev before first publish.
- Run tests and analysis for every package.
- Run `flutter pub publish --dry-run` for every package.
- Record Flutter, Dart, Android Gradle Plugin, Kotlin, Xcode, WeChat SDK, and QQ SDK versions.
- Confirm each README reflects the implemented native capabilities.
- Confirm privacy documentation is up to date.
